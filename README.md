# 🧪 Node TypeScript Starter Template

A modern, ready-to-use Node.js backend template built with TypeScript. This project provides everything you need to get started quickly with best practices: ESLint, Prettier, Husky, Jest, and commit conventions.

> ✅ Use this repository as a [GitHub template](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template) to start new projects effortlessly.

---

## 🚀 Features

- ⚡️ **TypeScript** with ESM and strict mode
- 🧹 **ESLint** + **Prettier**
- ✅ **Jest** for unit testing
- 🔐 **Husky**, **lint-staged**, and **Commitlint** for clean Git workflows
- 📁 Simple project structure with `src/`, `tests/`, and `dist/`
